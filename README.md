# VOD Review

Protótipo navegável de uma plataforma para revisão e análise tática de partidas de VALORANT.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Execução local

O projeto não exige compilação ou instalação de dependências. Abra o arquivo `index.html` diretamente no navegador ou sirva a pasta com um servidor HTTP local.

Exemplo com Python:

```bash
python -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

## Estrutura

```text
assets/        Recursos visuais e fontes
css/           Folhas de estilo
docs/          Documentação do domínio
js/            Comportamentos e navegação
index.html     Ponto de entrada do protótipo
```

## Escopo

Este repositório representa uma demonstração visual e funcional. Os dados são simulados localmente e não há backend, autenticação real ou integrações externas.
